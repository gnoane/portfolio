# Getting started

## 1. GitHub profile README
1. Create a public repository whose name is exactly your GitHub username.
2. Make sure the repository is public and initialise it with a README.
3. Replace its generated `README.md` with the `README.md` from this folder.
4. Replace every occurrence of `gnoane` with your real GitHub username.

## 2. Publish the website with GitHub Pages
1. Put `index.html`, `projects/` and the other website files in a repository (for example `portfolio`).
2. Replace `gnoane` in `index.html`.
3. Open the repository's **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Your site should be published at `https://gnoane.github.io/portfolio/` after deployment.

## 3. Before publishing
- Verify that your name, school and degree wording are accurate.
- Add a LinkedIn link only if you want to share it publicly.
- Add actual code, plots and data to project repositories before describing them as completed.
- Do not publish private coursework, personal data, or experimental files you do not have permission to share.
- Keep the distinction between completed work and planned work clear.
